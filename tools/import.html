bean-counter · data importer

Convert a Satisfactory Docs.json export into a bean-counter dataset. Everything runs in your browser — nothing is uploaded. The file is normally Docs/en-US.json in your game install and is UTF-16 encoded; that's handled for you.

Save the download to src/data/<version>/recipes.js, add the version to src/data/versions.js, and reference it from index.html. (Maintainers can equivalently run node tools/gen-data.js <version> — same code, same bytes.)
